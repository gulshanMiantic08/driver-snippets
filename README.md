# My Code Snippets

A collection of useful code snippets for Python and JavaScript development.

## Features

### Python Snippets
- `drivertemplate` - Selenium WebDriver setup
- `fastapiendpoint` - FastAPI CRUD endpoint
- `djangomodel` - Django model template

### JavaScript Snippets
- `reactcomp` - React functional component
- `asyncawait` - Async/await with error handling

## Installation

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "My Code Snippets"
4. Click Install

## Usage
Type the prefix and press Tab/Enter to insert the snippet.
